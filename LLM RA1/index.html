exercici2

  • XML1 la etiqueta <nom> no està tancada, tota etiqueta oberta s'ha de tancar 
             <persona>
            <nom>Anna</nom>
            <edat>25</edat>
         </persona>
  • XML2 les etiquetas distingeixen entre majúscules i minúscula 
             <persona>
          <nom>Anna</nom>
         </persona>
  • XML3 el valor de l'atribut edat=25 no va entre cometes. En XML els valors dels atributs sempre van entre cometes. 
              <persona edat="25">
           <nom>Anna</nom>
          </persona>
  • XML4 l'ordre de tancament de tags està invertit. 
           <persona>
        <nom>Anna</nom>
       </persona>
  • XML5 falta una etiqueta de nivell superior que contingui les dues etiquetes. 
           <persona>
        <nom>Anna</nom>
        <edat>25</edat>
       </persona>
  • XML6 la etiqueta s'ha de tancar exactament igual que com s'ha obert 
           <botiga>
        <producte>
         <nom>Monitor</nom>
         <preu>199.90</preu>
        </producte>
       </botiga>
